The game combines 2.5D pixel characters with 3D environments, semi-open exploration, dialogue-driven investigations, puzzle solving, time manipulation, and multiple endings.

## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Kill The Shadow**. This trainer enhances Lucas's investigation across Dark Tide City by helping manage character attributes, resources, deduction progress, and the Shadow's memory-reconstruction mechanics. It is designed to support exploration and story choices without changing the game's detective-focused structure.

**Target Audience:** Players who want to explore every investigation route, test different Strength, Spirit, and Charm builds, revisit branching choices, collect clues more freely, or experience multiple endings with less resource management.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## 📖 Detailed Feature Guide

### Movement & Exploration

Explore the districts of Dark Tide City and inspect available locations, characters, newspapers, notes, and other evidence. The trainer does not replace exploration; it helps remove progression pressure so you can investigate each area at your own pace.

### Tools & Inventory

Use the resource option only when money or investigation supplies are required for a case. Avoid changing values during dialogue scenes, clue transitions, or scripted events, and save after completing an investigation segment.

### World & Environment

Kill The Shadow features freely explorable districts including the Old Town District, Shipwreck Wharf, Pig Cage Walled City, and a deserted factory area. Use the trainer to support repeated visits and alternate approaches while following the game's case structure.

### Combat & Weapons

The game is primarily focused on investigation, dialogue, deduction, and Shadow-assisted memory reconstruction rather than action combat. Attribute support can help open physical or confrontational options when a case presents them, while the main benefit remains easier access to story and investigation routes.
